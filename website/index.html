03 / INTERPRETATION

Real measurements. Visible limitations.

One recorded execution

Precision follows the source

Values are parsed from SVG tooltip labels produced by the comparison suite. Unit conversions preserve their meaning; missing points are never converted to zero. Download the JSON to inspect labels and source hashes.

Concurrency and memory

Concurrency shows 4, 8 and 16 workers. The exported 1-worker series mixes fallback scenarios, so it is excluded. 8/16-worker results oversubscribe this 4-vCPU runner. RSS measures whole processes; it is not the database buffer size. Reader RSS compares four Rust/C readers, not Go.

Workloads and APIs matter

In lookup charts, 1M means query addresses, not database entries. The default City fixture inserts 4,097 IPv4 and 4,096 IPv6 networks. Random queries can miss. IPv6 absent, size scaling and RSS use separate fixtures.

Lookups include decoding on hits. Our reader uses typed borrowed City records; competitors use their own decoding APIs. This is a harness comparison, not an identical decoder microbenchmark.
